# ChefAI

AI-powered assistant for restaurant kitchens and chefs.

## Features

- Recipe guidance and scaling for larger batches
- Prep lists and kitchen task orchestration
- Dietary and allergy filtering
- Smart ordering suggestions based on inventory

## Status

Early-stage prototype. The repository is a clean starting point for the
ChefAI assistant workflow.

## Tech stack

- TypeScript / Node.js
- LLM APIs for generation and orchestration
